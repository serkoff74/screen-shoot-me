# Snapmark — референсы

## Что актуально

- `plan.md` — функциональный и архитектурный источник истины.
- `ui-spec.md` — визуальный и клавиатурный контракт.
- `svg/08-inline-region-layout.svg` и `png/08-inline-region-layout.png` — overlay-first компоновка.
- `gif/e-inline-selection-comment.gif` — полный текущий сценарий: живая страница → выделение → один скрытый
  capture → inline-редактор → двухстрочный комментарий → Copy/Save → короткий fallback.

Основной режим не открывает окно и не делает снимок до завершения выделения. Фрагмент замораживается на
исходном месте; вне него остаётся видимая, но заблокированная страница с затемнением 12%. UI графитово-синий,
аннотации коралловые `#FF4D2E` с halo. Комментарий — отдельная связанная карточка: его можно перемещать и
растягивать за видимую синюю рамку и девять handles 3×3; длинный текст переносится внутри.

## Архив

- `07-compact-blue-layout` и `d-full-arrow-comment-blue.gif` — предыдущий fullscreen/freeze визуальный контракт.
- `01–06` и GIF `a–c` — ранняя история интерфейса.

Архивные файлы не изменяются и не переопределяют требования `08/e`.

## Содержимое

- `svg/` — редактируемые векторные макеты.
- `png/` — растровые версии статичных макетов.
- `gif/` — анимированные UX-сценарии.
- `source/tabler-sprite.svg` — локальный источник согласованных SVG-иконок.
- `source/generate_full_flow_gif.py` — legacy-генератор GIF `d`.
- `source/generate_inline_flow_gif.py` — актуальный детерминированный генератор GIF `e`.

## Горячие клавиши

`Ctrl+Shift+S` — начать; `V A R O P T` — инструменты; в поле `Enter` применяет, `Shift+Enter` и
`Ctrl+Enter` добавляют строку, `Esc` отменяет правку; вне поля `Enter` копирует, `Ctrl+S` сохраняет,
`Ctrl+Z` / `Ctrl+Shift+Z` — undo/redo, `Delete` — удалить.
