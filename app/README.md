# Snapmark

Рабочее Manifest V3 Chrome-расширение с overlay-first выделением, аннотациями и комментариями.

## Установка

1. Выполнить `npm install` и `npm run build` в этой папке.
2. Открыть `chrome://extensions`, включить «Режим разработчика».
3. Нажать «Загрузить распакованное расширение» и выбрать папку `app/dist`.
4. Открыть обычную web-страницу и нажать иконку Snapmark, `Alt+Insert` или `Ctrl+PrintScreen`.

## Горячие клавиши запуска

- `Alt+Insert` — основная комбинация: обычная команда Chrome, работает, пока Chrome в фокусе. Сменить можно в `chrome://extensions/shortcuts` или кнопкой «Настроить в Chrome» на странице настроек Snapmark.
- `Ctrl+PrintScreen` — дополнительная, best-effort: клавиша `PrintScreen` не поддерживается commands API, поэтому Snapmark ловит её в content script, когда она доходит до страницы. Освободите `Ctrl+PrintScreen` в системных настройках Ubuntu/GNOME, если она занята. Если окружение рабочего стола перехватывает клавишу раньше страницы, запуск по ней не сработает — это ограничение платформы.
- Резерв — клик по иконке расширения.

## Что работает

- выделение прямо на живой странице без предварительного снимка или отдельного окна;
- ровно один скрытый захват после `pointerup`, DPR-aware crop и замороженный фрагмент на исходном месте;
- Shadow DOM overlay, 12% затемнение с лёгким blur и временная блокировка исходной страницы с полным восстановлением;
- стрелка, прямоугольник, овал, карандаш и текст;
- коралловые аннотации с авто-контрастным halo;
- подписи к фигурам: коралловая связь с исходным инструментом, видимая ручка и перетаскивание плашки;
- выбор/перетаскивание, синие рамка и handles, удаление;
- undo/redo, SVG-кнопки Tabler с tooltip и keyboard focus;
- Copy PNG с прямым clipboard-путём и offscreen fallback;
- Save As через `chrome.downloads.download({ saveAs: true })`;
- options-страница с цветом, толщиной, заливкой и поведением после копирования.
- fallback-окно только для страниц, куда Chrome запрещает внедрение, с объяснением причины.

Горячие клавиши: `V A R O P T` — инструменты; `Enter` в комментарии — применить; `Shift+Enter` и
`Ctrl+Enter` — новая строка; `Enter` вне поля — копировать; `Ctrl+S` — Save As; `Ctrl+Z` / `Ctrl+Shift+Z` / `Ctrl+Y` —
undo/redo; `Delete` — удалить; `Esc` — отменить ввод, снять выбор или закрыть.

## Разработка и проверка

```sh
npm test
npm run build
node scripts/browser-qa.mjs
```

Последняя overlay-first браузерная проверка и два примера находятся в `qa/overlay-iteration-1/` либо,
если понадобился второй визуальный цикл, в `qa/overlay-iteration-2/`.

Расширенные пресеты стрелок, отдельное перетаскивание подписи и стили `tag/numbered` остаются следующим
этапом развития; базовый рабочий сценарий из актуального GIF `reference/gif/e-inline-selection-comment.gif`
реализован полностью.
