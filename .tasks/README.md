# Задачи проекта

Каждая задача — отдельный Markdown-файл. Её статус определяется папкой:

- `pending` — задача сформулирована, но работа ещё не начата.
- `progress` — задача взята в работу.
- `completed` — задача выполнена и проверена.

Чтобы изменить статус, переместите файл задачи в соответствующую папку. Имя файла начинается с идентификатора `TASK-###`, который не меняется при перемещении.

Папки статусов (`pending`, `progress`, `completed`) всегда должны быть в git, даже пустыми — поэтому в каждой лежит `.gitkeep`. Не удаляйте эти папки и их `.gitkeep`.

В каждой задаче фиксируются проблема, ожидаемый результат и критерии приёмки. По завершении при необходимости добавляется короткая заметка о реализации и проверке.
